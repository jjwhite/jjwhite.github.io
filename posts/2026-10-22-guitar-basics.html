An Illustrated Guide to Music Theory Basics on Guitar

2026-10-22

Notes

Each string on the guitar corresponds to a specific note. For this post we're going to assume standard tuning which means that the strings are tuned in this order:

E(thickest string) A D G B E(thinest string)

There is a good mnemonic device to help remember this order: Eddie Ate Dynamite Good Bye Eddie. Playing any string open plays that strings note. In order to play different notes you can press down the string in the gaps on the guitar neck. These are called frets. Each fret corresponds to a semitone also known as a half step. So, moving up one fret is a half-step and 2 frets is a full-step. As you move up the neck of the guitar, holding down each fret, the notes you play when strumming the string follow a specific pattern:

A -> A# -> B -> C -> C# -> D -> D# -> E -> F -> F# -> G -> G# -> A

It doesn't matter what note you start on, you just follow the pattern from the point. The pattern is circular when you reach the starting point, you just keep going around.

Scales

There are many different types of scales but for the purposes of this article, we'll be discussing the minor and major scales which are both diatonic scales.

Scales are made up of whole and half steps. As discussed above, on a guitar, each fret is a half step. So, 2 frets for a whole step. If we use the letter "W" to represent a whole step and "H" to represent a half step, we can describe the major and minor diatonic scales as:

Major: W-W-H-W-W-W-H

Minor: W-H-W-W-H-W-W

A scale is named by its root note. So, a G Major scale starts on G and follows the major scale pattern from there. A G Minor scale starts on G and follows the minor scale pattern.

You can see that they share many notes with the only differences being A# instead of B, D# instead of E, and F instead of F#.

Intervals

The gaps between notes are called intervals and they are built from a quality and a number. Examples are: Major(quality) 2nd(number) and Perfect(quality) 5th(number).

Chords

Now that we understand notes and intervals we can use those building blocks to start looking at chords. Chords are built using note combinations called triads. A triad is a three note combination that makes up chords. They are based on the root note and then stacked 3rds.

  • Major Chords: Root Note + Major 3rd + Perfect 5th (Frets: 0, 4, 7)
  • Minor Chords: Root Note + Minor 3rd + Perfect 5th (Frets: 0, 3, 7)
  • Sus2 Chords: Root Note + Major 2nd + Perfect 5th (Frets: 0, 2, 7)
  • Sus4 Chords: Root Note + Perfect 4th + Perfect 5th (Frets: 0, 5, 7)
  • Diminished Chords: Root Note + Minor 3rd + Lowered 5th (Frets: 0, 3, 6)
  • Augmented Chords: Root Note + Major 3rd + Raised 5th (Frets: 0, 4, 8)

If you had really long fingers you could play chords on a single string by playing the root note and then stretching your exceptional fingers to reach down the fretboard based on the list above. Of course, we don't play chords that way so let's explore some real chords and the notes that make them.

We'll start with an easy one: E Major

2 3 1

if we look at each string, these are the notes:

E(open), B(2nd fret), E(2nd fret), G#(1st fret), B(open), E(open)

Now, let's compare that to the notes in the E major scale. Remember, we can build a major diatonic scale with the pattern: W-W-H-W-W-W-H. So, for E major that would look like this:

E, F#, G#, A, B, C#, D#

You can see that all the notes of the chord exist in the major scale.

The same is true of E Minor:

2 3

Notes: E(open), B(2nd fret), E(2nd fret), G(open), B(open), E(open)

And now the E minor scale (W-H-W-W-H-W-W)

E, F#, G, A, B, C, D

As with the major chord, the notes of the minor chord all exist in the E minor scale.

A few things to notice here.

  1. The only difference between the E major and E minor chords is that E major has a G# and E minor has a G. Everything else is the same.

  2. In both chords, there are repeated notes (the E and B in both cases). This is called doubling and you can have either an octave doubling which is when the same note is played at different octaves or unison doubling when it's the same note at the same octave.

My original understanding was that chords are built from notes of a scale. But that's not necessarily true. It can be true when you're talking about the diatonic scales in that a G major chord will only contain notes in teh G Major scale and a G minor chord will only contain notes in the G minor scale but that is sort of just a coincidence, not a rule.

Roman Numeral Notation

If you’re looking at any given scale, a chord can be made by using each note in the scale as the root. These are usually notated with roman numerals like this:

I, II, III, IV, V, VII, VIII

For a given scale you would use uppercase and lowercase to indicate whether it’s a major or minor chord.

This happens because you build each chord by taking the root + 3rd + 5th. Depending on where those notes land it could be a major or a minor chord. This is due to the fact that the fretboard on a guitar is not uniform as we talked about a couple of weeks ago.

As an example let’s stay in the G Major Key. That scale is: G-A-B-C-D-E-F#

So, the chord for A is: A(root), C(3rd), E(5th)

Now, if we look at what we learned last week:

  • Major Chords: Root Note + Major 3rd + Perfect 5th (Frets: 0, 4, 7)
  • Minor Chords: Root Note + Minor 3rd + Perfect 5th (Frets: 0, 3, 7)

if we start at A on the fretboard and move to the next note in the chord (C) that is only 3 frets away so it’s a MINOR 3rd instead of a major so the chord is minor which is why for G Major Key the notation is:

I, ii, iii, IV, V, vi, vii°

  • I (G major): G – B – D (Major)
  • ii (A minor): A – C – E (Minor)
  • iii (B minor): B – D – F♯ (Minor)
  • IV (C major): C – E – G (Major)
  • V (D major): D – F♯ – A (Major)
  • vi (E minor): E – G – B (Minor)
  • vii° (F♯ diminished): F♯ – A – C (Diminished)
